# Intrans - 内联AI翻译助手

## 背景

这本质上是一个AI翻译助手，只不过它将改变了用户的使用流程。

原本，用户一般先将自己想要翻译的文字，例如中文，写道翻译软件中，等翻译完毕之后，再将翻译之后的文本复制到自己想要填写的地方。

这种非常不流畅的过程打乱了用户原本的工作、学习体验。

而 intrans 将翻译过程内敛到了用户的使用场景中，当用户需要翻译的时候，只需要按动快捷键，即可得到一个在用户输入光标附近（类似输入法按下的时候，弹出的输入法窗口会自动移动到光标下方）的一个“悬浮”的窗口。同时，窗口焦点也会随之转移到 intrans 中，用户即可输入自己想要翻译的源文本，按下 enter 按键之后，程序将会和各种翻译服务进行传输信息，得到几个候选项，用户按动候选项的序号（1，2，3），即可将翻译后的文本填充到刚才的光标处。如果用户觉得这些选项都不满意，即可按动 / 按钮，继续给 AI 进行多端交流，纠正结果。

## 技术架构

考虑到本项目要使用 LLM 相关服务的调用，所以选用了当前 LLM 框架最流行的语言 TypeScript 技术。考虑到跨平台，即采用了 Tauri 桌面技术。

1. 前端 - Typescript + Vue + TailwindCSS
2. 桌面技术 - Tauri - Rust
3. LLM 框架 - LongChain TypeScript Version

## 前端 UI

### 窗口

由于想要实现一种“悬浮”或者“内联”的效果，所以窗口是无边框的。

### 布局

前端界面应尽可能的保持简单，但是需要保留基本的用户交互逻辑和界面展示信息的UI界面。

它基本上类似于当前流行的 AI IDE 中的 Ctrl + I 快捷键呼出的一个内联的输入框，左边可以选择模型，右边是发送按钮，中间时输入框。

当用户输入了一些信息之后，界面会随之拓展，以显示用户输入的历史信息。当 LLM 返回一些选项的数据之后，UI 界面会随之展示各个选项，如果不满意，则重新输入（但是之前的历史信息保留），总的来说，“选项”同一时间只会出现最新的那一次的回复。

当用户选择了某个选型之后，界面退出。

### 整体要求

UI 要是扁平化的，简介的，现代化的。

## 功能

用户如果再次按动快捷键呼出 Instans 的界面，可以按 , 和 . 按钮，再上一次的记录或者下一次的记录中来回切换，与此同时，UI界面中的历史信息也会随之改变。

### 设置界面

用户可以按 Ctrl + , 来启动设置界面，这个界面是一个有边框的普通界面。

### LLM

当前的 LLM 应该使用 LangChain 框架，但是只用到最简单的对话功能，并不涉及 Agent 的内容。

例如我需要有多轮对话的能力，并且可以选择不同的LLM提供商（通过在设置中配置）

## 托盘

此程序应该有一个托盘，右键可以打开设置，左键可以打开 Instrans 的主界面（无边框的翻译界面）。

## 代码要求

1. 应该具备良好的文件布局结构
2. 对于 css 来说，vue 应该把各个组件/样式包装起来，而不是一股脑的写到一个文件中
3. 大部分的 UI 都应该使用组件来实现，而不是直接写在模板中
4. 具备可维护性，代码应该具备良好的可读性，可维护性，可扩展性
